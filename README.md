# NoMisHub

📰 NoMisHub: Collaborative News Platform
UI/UX Design & Full-Stack Development | LBAW @ FEUP

🎨 Design & Experience (The "UI/UX" Side)
User-Centered Design: Developed a clean and intuitive interface, focusing on news readability and seamless navigation.

Responsive Architecture: Ensured the platform is fully adaptive (Desktop & Mobile), with a specific focus on the usability of the Admin Dashboard on small screens.

Visual Consistency: Defined a color palette and typography that convey trust and clarity in information sharing.

💻 Technical Implementation (The "Dev" Side)
Full-Stack Development: Built from scratch using PHP, HTML5, and CSS3.

Core Features: Implemented a robust User Authentication system, a functional Search Engine, and a comprehensive Admin Panel for content moderation.

Data Management: Structured and integrated a SQL database for efficient management of news, comments, and user profiles.

💻 Tech Stack
`Laravel` `PHP` `Docker` `PostgreSQL` `HTML5` `CSS3` `JavaScript`
